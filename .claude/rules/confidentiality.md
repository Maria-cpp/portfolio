# Confidentiality & Anonymization Rules

## Client Anonymization (Mandatory)

This is a public portfolio. Client identities must be protected:

| Real Name | Public Reference |
|-----------|-----------------|
| FBR (Federal Board of Revenue) | "federal regulator" |
| Sindh Secretariat | "provincial government secretariat" |

- Real client names appear ONLY in the private CV (Maria_Naseem_CV.pdf), never in code or visible UI text.
- Reason: Prototypes not yet fully deployed; client confidentiality agreements apply.
- Government sector projects use cyan badges. ZumfluxAI projects use pink badges.

## Sensitive Files

Never commit or expose:
- `.env` or `.env.local` files
- Credentials or API keys
- Internal client documents
- Draft proposals or SOWs

## NDA Compliance

Some project details are under NDA. When describing projects:
- Focus on technical approach and architecture, not business specifics.
- Use generic sector terms instead of specific organization names.
- Do not include internal metrics, revenue figures, or contract details.
